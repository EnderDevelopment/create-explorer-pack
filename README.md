# Ender Exploration Modpack

A balanced exploration-focused Minecraft modpack for Forge 1.20.1 that combines Create's mechanical automation with Farmer's Delight cooking, Alex's Mobs creatures, Terralith biomes, Better End and Better Nether dimensions, boss mods, new materials, and exploration compasses. The pack curates about 30 mods tuned so every new power source, material, or tool costs real effort through dangerous mobs, boss-gated content, and travel-based exploration without teleport cheats. The result is a survival experience where adventure, building, and combat stay meaningful from early game to end-game challenges.

## Install

1. Install Minecraft Java Edition and run it once to generate the game directory.
2. Install Minecraft Forge 47.3.0 for Minecraft 1.20.1 from the official Forge website.
3. Open your Minecraft `mods` folder:
   - Windows: `%appdata%\.minecraft\mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
4. Download each mod from the official sources listed in `MODLIST.md` (CurseForge, Modrinth, or GitHub project pages), ensuring you get the version compatible with Forge 1.20.1.
5. Copy all downloaded mod jars into the `mods` folder.
6. Copy the entire `config/` folder from this repository into your `.minecraft/config` folder to apply the balance tuning.
7. Launch Minecraft with the Forge profile. The mods will load automatically.

## Use

1. Start a new world or load an existing one with the Forge profile.
2. Use the **Explorer's Compass** to locate biomes and structures, and the **Adventurer's Compass** to find bosses and the Wither.
3. Explore Terralith's 95+ new biomes and YUNG's Better Caves for underground adventures.
4. Progress through the tech tree with **Create** and its addons, balancing automation with resource costs.
5. Grow crops and cook with **Farmer's Delight** and **Croptopia** for renewable food.
6. Brave **Better End** and **Better Nether** dimensions to earn new materials like Enderite and Netherite alternatives, gated behind their bosses.
7. Challenge end-game bosses from **Bosses of Mass Destruction** and **Cataclysm** for the strongest loot.
8. Use **JourneyMap** for navigation, and **Traveler's Backpack** for extra storage.
9. Refer to **JEI** for all new recipes, **Jade** for block info, and **AppleSkin** for hunger details.
10. Tune keybinds with **Controlling** to manage all new controls.
11. For servers, apply the same `mods` and `config` folders on the server, and set `view-distance=10` and `simulation-distance=8` as recommended in `server.properties.example`.
